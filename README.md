# Layout Practice Pack: Flexbox, Grid & Positioning

Five webpage designs for students to rebuild with HTML and CSS. Each project comes with design images (desktop and mobile), original image and icon assets, a brief with specs, and starter files.

| # | Project | Level | Main focus |
|---|---|---|---|
| 1 | Mama Put Kitchen (food delivery landing page) | Beginner | Flexbox |
| 2 | Lagos Lens (photography portfolio) | Beginner to intermediate | CSS Grid |
| 3 | FarmTrack (farm dashboard) | Intermediate | Grid template areas, app layouts |
| 4 | Garden City Fest (music festival page) | Intermediate | Positioning and z-index |
| 5 | Naija Beats (music web player) | Advanced capstone | All three together |

## How each project folder is organised

```
0X-project-name/
  BRIEF.md          ← start here: tasks, colours, fonts, measurements
  design/           ← the target: desktop (1440px) and mobile (390px) screenshots
  assets/
    images/         ← JPG illustrations
    icons/          ← SVG icons (24×24, stroke uses currentColor/black)
    logo.svg
  starter/
    index.html      ← complete HTML content
    style.css       ← colours, fonts, reset, and TODO list
```

Projects 2, 4 and 5 have two kinds of design images: `full-page` (the whole page, with fixed bars hidden so nothing overlaps) and `first-screen` (what appears on load, showing where fixed elements sit).

## Suggested use

- One project per week, in order. Each one adds skills on top of the last.
- Students work in `starter/`. The HTML already links to `../assets/`, so images load as long as the folder structure stays the same.
- Students can write their own HTML instead if you want a harder version: tell them to ignore `starter/index.html`.
- Fonts load from Google Fonts, so students need an internet connection.
